# cpgame 水果消除游戏 — 技术全景文档

> 复刻自微信小游戏《闯关乐消除 / 消个水果》。Cocos Creator 3.8.8 + TypeScript + 2D 物理（Box2D）。

---

## 1. 项目概览

| 项 | 值 |
|---|---|
| 引擎 | Cocos Creator 3.8.8 |
| 语言 | TypeScript |
| 分辨率 | 750 × 1334（竖屏，fitWidth） |
| 物理 | 内置 PhysicsSystem2D（Box2D） |
| 场景数 | 2（欢迎页 + 主游戏） |
| 当前关卡数 | 3（配置化，可扩展） |
| 代码量 | 约 630 行 TS（不含引擎） |

**核心玩法**：顶部预置一批水果（静态刚体）→ 玩家点击任意一个 → 该水果变动态刚体下落 → 落到 V 型草皮斜板 → 滚入中心窄槽堆积 → 两个同级水果接触即消除 → 堆过警戒线判负 / 全部消除判胜。

## 3. 游戏流程

```
main.scene（欢迎页）
  │  点击「开始游戏」
  ▼
game.scene（主游戏）
  │  1. 读 localStorage 当前关卡号
  │  2. LevelConfig.load() 加载 levels.json
  │  3. 加载水果贴图 / 漏斗贴图
  │  4. buildWorld() 搭建物理世界（斜板/窄槽/隐形墙）
  │  5. buildStage() 按配置生成静态水果
  ▼
  玩家循环：
    ├─ 点击顶部水果 → 静态转动态 → 下落
    ├─ 水果落斜板 → 滚入窄槽 → 堆积
    ├─ 两个同级水果接触 → 消除 + 得分
    ├─ 每 N 秒未点击水果整体下移（时间压力）
    └─ 警戒线上方有静止水果 → 判负
  │
  ├─ 全部消除 → 过关 → 下一关号写入 localStorage
  └─ 桶满溢出 → 失败 → 重试/回主页
```

## 4. 物理世界几何（关键常量）

设计分辨率 750×1334，y 轴向上，原点在屏幕中心。

```
y=+667 ─────────────── 画布顶
  │   [顶部 HUD：返回/记分/提示]
  │
  │   ● ● ● ● ● ●      ← 待投放水果（静态刚体，配置驱动）
  │   ● ● ● ● ● ●
  │   ● ● ● ● ● ●
  │
y=-400 ─────────────── 警戒线（BOX_RIM_Y，桶口）
  ╲                   ╱     ← V 型草皮斜板（FUNNEL_TOP_Y=-250 外端）
   ╲                 ╱
    ╲               ╱
     ╲_____________╱       ← CLIFF_Y=-400（内端，收窄到竖槽）
     │             │       ← 窄槽侧壁（半宽 50）
     │             │
     │     ●●●     │       ← 水果堆积区
     │     ●●●     │
     └─────────────┘       ← 托盘平底（THROAT_Y=-660）
y=-667 ─────────────── 画布底
```

| 常量 | 值 | 含义 |
|---|---|---|
| `BOX_RIM_Y` | -400 | 判负线：水果堆过此线静止 0.5s 即判负 |
| `FUNNEL_TOP_Y` | -250 | V 型斜板外端（宽口） |
| `CLIFF_Y` | -400 | V 型斜板内端（=桶口，收窄到竖槽） |
| `THROAT_Y` | -660 | 窄槽托盘平底 |
| `RAMP_OUTER_X` | ±375 | 斜板外端 x |
| `RAMP_INNER_X` | ±50 | 斜板内端 x（窄槽半宽） |
| `FRUIT_RADIUS` | 40 | 所有水果统一半径 |
| `RAMP_FRICTION` | 0.15 | 斜板低摩擦，保证水果能滚下 |
| `FRUIT_FRICTION` | 0.55 | 水果摩擦 |
| `CHUTE_FRICTION` | 0.4 | 窄槽壁摩擦 |

**隐形墙**：x=±392，从 y=667 到 y=-660，无视觉，纯碰撞体，防止水果滚出画布。

## 5. 关卡配置系统（levels.json）

### 5.1 文件结构

```json
{
  "levels": [
    {
      "level": 1,
      "descendInterval": 25,
      "descendStep": 25,
      "gravity": -750,
      "fruits": [
        { "x": -240, "y": 620, "level": 1 },
        { "x": -120, "y": 620, "level": 2 }
      ]
    }
  ]
}
```

### 5.2 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `level` | number | 关卡号（1 开始） |
| `descendInterval` | number | 定时下坠间隔（秒） |
| `descendStep` | number | 每次下坠距离（px） |
| `gravity` | number | 重力加速度（默认 -750） |
| `fruits[]` | array | 每个水果的位置和种类 |
| `fruits[].x/y` | number | 水果坐标（设计坐标系） |
| `fruits[].level` | number | 水果种类 1~5（对应 level1~5.png） |

### 5.3 当前 3 关配置

| 关卡 | 水果数 | 种类分布 | 下坠节奏 | 重力 |
|---|---|---|---|---|
| 1 | 12 | lv1×8, lv2×4 | 25s / 25px | -750 |
| 2 | 20 | lv1×8, lv2×12 | 20s / 30px | -750 |
| 3 | 28 | lv1×4, lv2×12, lv3×4, lv4×8 | 15s / 35px | -800 |

**规则**：每个 level 的水果数必须是偶数（成对消除，否则无法通关）。

### 5.4 加载流程

`LevelConfig.load()` → `resources.load('data/levels', JsonAsset)` → 缓存到静态变量 → `GameRoot.start()` 回调里读当前关配置。

进度存储：`localStorage['cpgame_level']`，过关后自动 +1。

## 6. 核心代码逻辑（GameRoot.ts）

### 6.1 水果状态机

```
[创建] 静态刚体 Static + CircleCollider2D + Fruit(dropped=false)
   │  玩家点击
   ▼
[掉落] body.type = Dynamic, linearVelocity=(0,-60), dropped=true
   │  受重力下落
   ▼
[堆积] 滚入窄槽，静止稳定
   │  同级水果接触 (onBeginContact)
   ▼
[消除] 金色爆裂特效 → node.destroy() → score+=10
```

### 6.2 消除判定（onBeginContact）

```typescript
// 两个掉落水果接触时触发
if (a.level !== b.level) return;        // 种类不同不消除
if (!a.dropped || !b.dropped) return;   // 未掉落不消除
if (eliminating.has(a) || eliminating.has(b)) return;  // 已在消除队列
// scheduleOnce(0.05s) 后 eliminate()
```

### 6.3 判负判定（update）

每帧遍历所有掉落水果：
1. `y < OVERFLOW_MIN_Y (100)` —— 已进入桶区（排除顶部被挡的）
2. `y > BOX_RIM_Y (-400)` —— 在警戒线上方
3. 速度阈值：`linSpeed² < 4 && angSpeed < 0.5` —— 真正静止
4. 持续 0.5s → `showResult(false)`

### 6.4 定时下坠（descendStage）

每 `descendInterval` 秒，所有未点击水果 `y -= descendStep`。
如果未点击水果 y < 警戒线 + 100px → 直接判负（压到桶口了）。
