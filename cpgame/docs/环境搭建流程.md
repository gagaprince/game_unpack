# Cocos Creator + AI 辅助开发环境搭建流程

> 用途：记录 cpgame 复刻工程从零搭建开发环境的完整步骤，供新机器或新项目复用。
> 整理日期：2026-10-14
> 适用平台：macOS（Apple Silicon）

## 二、安装 Cocos Dashboard 与 Creator

1. 浏览器打开 Cocos 官网下载 Dashboard：<https://www.cocos.com/creator-download>
   - 注意：`download.cocos.com` 对 curl 直接下载返回 403，必须用浏览器下载，不要走命令行。
2. 安装 Dashboard 后登录 Cocos 账号。
3. 在 Dashboard「编辑器」标签页安装 **Cocos Creator 3.8.8**（与目标游戏同版本，避免资源/序列化兼容问题）。
4. 版本选择：3.x 是 TypeScript 新架构（2D/3D 统一、Box2D wasm、Bundle 体系），2.x 是老 JS 架构；新游戏和 AI 工具链都只支持 3.8+，复刻 3.8.8 的游戏必须用 3.x。

## 三、创建工程

1. Dashboard「项目」→ 新建 → 选择模板 **Empty(2D)**。
2. 项目名 `cpgame`，路径 `/Users/zidong.wang/aiwork/game_unpack/cpgame`。
3. 首次打开后编辑器自动生成 `library/`、`temp/`、`.creator/` 等目录。
4. 在「项目 → 项目设置 → 功能裁剪」确认引擎模块（empty-2d 模板默认已含）：
   - `physics-2d-box2d`（2D 物理，核心）
   - `ui`、`2d`、`tween`
   - `spine-3.8`、`dragon-bones`、`particle-2d`（动画特效）
   - 配置实际记录在 `settings/v2/packages/engine.json`。

## 四、工程目录骨架

```
cpgame/
├── assets/
│   ├── scene/                 # 场景
│   ├── scripts/{core,game,ui,system,data,utils}
│   └── res/{texture,atlas,prefab,audio,anim,config}
├── build-templates/           # 微信构建模板定制
├── extensions/                # 编辑器扩展（Funplay 装这里）
├── settings/                  # 项目设置（引擎模块、构建等）
└── package.json               # 工程描述（含 creator 版本、工程 uuid）
```

空目录用 `.gitkeep` 占位，编辑器可正常识别。

## 五、安装 Funplay MCP（AI 直连编辑器）

仓库：<https://github.com/FunplayAI/funplay-cocos-mcp>（106 个工具，默认开放 39 个 core 工具）

### 1. 放置插件

```bash
cd /Users/zidong.wang/aiwork/game_unpack/cpgame
mkdir -p extensions
git clone --depth 1 https://github.com/FunplayAI/funplay-cocos-mcp.git extensions/funplay-cocos-mcp
```

- 插件零外部依赖（`dependencies: {}`）、代码已编译，**不需要 `npm install`**。
- 也可在 Cocos Store 搜「Funplay MCP」一键安装；或在编辑器 `Funplay → MCP 设置` 里点「为所有项目安装」（装到 `~/.CocosCreator/builtin-extensions/<版本>/`，同版本所有工程通用）。

### 2. 加载扩展

- 重启 Creator，或在「扩展 → 扩展管理器」点刷新重新扫描。
- 加载成功后顶部主菜单栏出现 **Funplay** 菜单。

### 3. 启动服务

- 菜单 `Funplay → MCP 服务`（英文界面为 `MCP Server`）打开面板。
- 确认 Server 启用，记下面板显示的实际地址。
- **注意：每个新项目分配 20000–29999 的独立端口（本项目为 23164），不是文档默认的 8765**，一律以面板显示为准。

### 4. 配置 Codex

向 `~/.codex/config.toml` 的 `[mcp_servers]` 区域追加：

```toml
[mcp_servers.cocos-cpgame]
url = "http://127.0.0.1:23164/"
```

也可以在 MCP 面板 `MCP Client Config` 选 Codex 点「One-Click Configure」自动写入。
改完配置必须**重启 Codex** 才能加载 MCP 工具。

### 5. 验证链路

```bash
curl http://127.0.0.1:23164/health
# 期望：{"ok":true,"name":"Funplay Cocos MCP - cpgame","version":"0.6.7",...}
```

Codex 重启后调用 `get_project_info`、`get_editor_state` 等工具，能返回项目实时信息即成功。

## 六、安装项目 Skills（可选但推荐）

编辑器菜单 `Funplay → MCP 设置 → 项目 Skills`，选择 Codex 一键安装：

- `funplay-cocos-mcp-workflow`：场景/节点/Prefab/TS 诊断/截图/预览的标准操作循环
- `funplay-cocos-ui-composition`：移动端 UI 适配、Widget/Layout、安全区、滚动列表等

安装位置：`cpgame/.agents/skills/`。
注意：Skills 跟随项目目录，Codex 工作区根需是 `cpgame` 才会自动加载；在上级目录打开时可由 AI 手动读取遵循。

## 七、安装微信开发者工具

1. 浏览器下载 arm64 稳定版：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 安装后打开「设置 → 安全设置 → 服务端口」并开启，否则 Creator 构建后无法自动唤起调试。
3. CLI 路径：`/Applications/wechatwebdevtools.app/Contents/MacOS/cli`。
4. 首次构建微信小游戏后，用它导入 Creator 产物 `build/wechatgame` 目录（真机调试/上传需微信小程序 AppID）。

## 八、已知坑备忘

1. **不要从终端启动 Cocos Creator**：Electron 经 LaunchServices 启动会 SIGABRT 崩溃（崩溃日志在 `~/Library/Logs/DiagnosticReports/CocosCreator-*.ips`）。一律从 Dashboard 或 Finder 打开。
2. **Cocos 下载链接反爬**：curl/wget 下 Dashboard 返回 403，用浏览器。
3. **MCP 端口按项目分配**：多项目并存时每个工程端口不同，配置前先看面板。
4. **场景文件不要手写**：`.scene` 含节点 UUID 等序列化结构，场景/节点优先通过 MCP 或编辑器创建。
5. **功能裁剪影响构建**：预览正常不代表微信包正常，构建前在功能裁剪里核对 Box2D/Spine 等模块。
